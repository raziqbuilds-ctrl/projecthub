# ProjectHub

ProjectHub is a student project collaboration platform designed to help
students discover projects, find teammates, showcase their skills, and
collaborate on real-world projects.

## Project Structure

- `Designing/` - System design, database design, business rules, and architecture documentation
- `backend/` - Java Spring Boot backend
- `frontend/` - Frontend application

## Technology Stack

### Backend
- Java
- Spring Boot
- PostgreSQL
- Spring Data JPA
- Maven
